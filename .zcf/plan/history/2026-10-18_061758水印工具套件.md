# 水印工具套件（方案 2：双层水印套件）实施计划

> 研究依据：`隐形水印研究.md`（17 维度 + 本机实测）
> 位置：`scripts/wmtools/` ｜ 零新依赖 ｜ 全 CPU ｜ KISS/YAGNI

## 分层
- 合规层：元数据隐式标识（C2PA 签名 + XMP）+ 元数据清洗（剥 H3 workflow Prompt）+ 显式角标占位（P2）
- 水印层：图像 dwtDctSvd 128-bit（实测 0 误码路线）；视频关键帧 overlay + 重编码 CRF18；检测端多基准重采样 + CRC 自校验
- 指纹层：pHash 五元组 JSONL 库

## 步骤
- S1 wm_id.py：ID = 项目hash32b + epoch天数16b + 随机序号48b + CRC32 32b（CRC 兼做水印存在性判定）
- S2 wm_image.py：embed（dwtDctSvd）/ decode（原生→1080p→720p 多基准，任一 CRC 通过即命中）
- S3 wm_c2pa.py：clean_video（-map_metadata -1 剥 Prompt）/ sign / verify
- S4 wm_video.py：embed（ffmpeg overlay eq(n,0/中点) 单命令重编码 CRF18，音轨 copy）/ detect（首中尾三帧投票）
- S5 wm_fingerprint.py：pHash+dHash+sha256+水印ID+C2PA UUID → data/registry.jsonl（gitignore）
- S6 wm_detect.py：元数据层→水印层→指纹层；证据分级 OURS_SIGNED > SIGNED > ID_MATCH(库内水印) > WM_FOUND > DIST_MATCH > PROBABLE_AI > UNKNOWN
- S7 wm_cli.py + README + 端到端测试

## 铁律
- 链序：embed → clean → sign（签名绑定哈希必须最后）
- pipeline 幂等：前置 detect，已 ID_MATCH 则跳过
- 依赖 pinned：invisible-watermark / c2patool 0.27.22 / imagehash / ffmpeg（版本变更须回归实测矩阵）

## 验收
1. NB21 图：embed → JPG q85 → 缩放回采 → detect = ID_MATCH
2. H3 mp4：clean（Prompt 消失）→ 关键帧嵌 → 重编码 → detect = ID_MATCH
3. C2PA verify = Valid，assertions 含 com.nanocanvas.meta
4. 指纹库：同图命中、异图不误报
