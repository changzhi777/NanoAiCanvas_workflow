# wmtools 三域集成实施计划

> 研究依据：`隐形水印研究.md` 维度二十（WAM 逐帧视频 crf30 三帧 100% / WavMark AAC 48k 100% / AudioSeal py3.14 硬不兼容止损）
> 目标：deep tier 三域齐发——图像 WAM（已有）+ 视频 WAM 逐帧（换装）+ 音频 WavMark（新增）

## 架构
- engines/wam_engine.py 扩展 domain=both：embed_video/extract_video_votes（逐帧 MPS/CPU）
- engines/audio_engine.py 新增：WavMark L2 音频（16k 重采样、wave IO、16-bit pack + registry 关联）
- engines/videoseal_engine.py 保留实验性 --engine
- wm_detect：音频分支（WavMark+ID3）+ 视频 deep 换 WAM 投票
- wm_cli：pipeline 音频 deep 分支 + 视频 deep 换装 + selftest 扩展

## 关键决策
- 视频 deep = WAM 逐帧单嵌（L1+L2 同帧双嵌未测，VideoSeal 互扰教训 → 不叠加）
- 视频检测 deep = L1 关键帧 + WAM 三帧投票并行
- 音频容量：WavMark 16-bit payload（registry 关联取全 ID，rec['wavmark']）
- 音频 light = ID3 元数据声明；deep = WavMark 深嵌

## 步骤
- S1 audio_engine.py
- S2 wam_engine 视频扩展
- S3 wm_detect 融合
- S4 wm_cli + selftest
- S5 验收（deep 视频 crf30 ≥2/3、deep 音频 AAC48k 100%、light 零回归、engine 可溯）+ README + 归档 + commit

## 验收
1. deep 视频：WAM 逐帧 → crf30 → 三帧投票 ≥2/3
2. deep 音频：WavMark → AAC 48k → 检测命中
3. light 零回归（selftest 全绿）
4. 报告 deep 层含引擎字段
