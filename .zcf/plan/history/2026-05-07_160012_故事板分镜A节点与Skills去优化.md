## 执行计划

### 步骤1：SkillsTaskNode 去除提示词优化

**文件**: `src/components/nanoai-workflow/nodes/SkillsTaskNode.tsx`

操作：
- 移除 `OPTIMIZE_SYSTEM_PROMPT` 常量
- 移除 `optimizePromptWithGLM` 函数
- 移除 `GLM_CONFIG` import
- 移除 `Sparkles`, `RotateCcw` 图标 import（如不再使用）
- 移除 `IMERawTextarea`, `VoiceInput` import（如不再使用）
- 移除状态：`rawPrompt`, `optimizedPrompt`, `editablePrompt`, `isOptimizing`

- 移除 UI 中的「提示词优化」区域（Sparkles 区域 + 可编辑文本框 + 重置按钮）

- 按钮文案改为固定「执行生成」

### 步骤2：新建 StoryboardShotANode

**文件**: `src/components/nanoai-workflow/nodes/StoryboardShotANode.tsx`（新建）

节点设计：
- 类型：`storyboard_shot_a`
- 输入：text（文本提示词/故事描述）
- 输出：image（分镜图片）
- 内嵌流程：输入文本 → GLM-4.5-Air 提示词优化 → SkillQueueAdapter 生图 → 输出图片

UI 结构：
- 状态指示器（复用 SkillsTaskNode 的 StatusIndicator 模式）
- 文本输入区（可直接输入或从上游接收）
- 提示词优化区域（Sparkles 图标，优化/重新优化按钮，优化后文本可编辑）
- 步骤动画（TaskStepAnimation）
- 结果预览（网格展示）
- 执行/取消按钮
- Handle：左侧 target（text-in），右侧 source（result-out）

从 SkillsTaskNode 迁移的代码：
- `OPTIMIZE_SYSTEM_PROMPT` 常量
- `optimizePromptWithGLM` 函数
- 提示词优化 UI 区域
- StatusIndicator / ResultPreview 子组件
