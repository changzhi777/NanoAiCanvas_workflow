## 阶段 D：生产环境问题排查

### 问题 1：Nginx `/api/` 路径重复
- **现象**：前端请求 `/api/auth/login` → Nginx 转发为 `http://api/api//auth/login`
- **解决**：修改 Nginx 配置 `proxy_pass http://api;`（移除末尾斜杠）

### 问题 2：cz@nanoai.fun 密码哈希损坏
- **现象**：密码哈希存储不完整（只有 "b2"）
- **解决**：使用 Python + psycopg2 直接更新 PostgreSQL nanoai 数据库

### 问题 3：curl URL 编码问题
- **现象**：`&remember_me=false` 被误解为参数分隔符
- **解决**：使用 `--data-urlencode` 替代 `-d`

### 验证结果
```bash
curl -X POST https://nanoai.fun/api/auth/login \
  -H "Content-Type: application/x-www-form-urlencoded" \
  --data-urlencode "username=cz@nanoai.fun" \
  --data-urlencode "password=cz777777+"
→ 成功返回 access_token
```
