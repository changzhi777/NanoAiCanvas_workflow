# 资产库功能升级计划

**创建时间**: 2026-05-02 15:53:25
**状态**: 已完成（资产库已重构为7类+批量操作+TVC）

## 目标
基于现有数据库和后端，升级扩展资产库功能

## 计划内容

### 1. 文件夹管理
- 利用 category 字段的 parent_id 实现层级
- 前端：左侧文件夹树形视图
- API: GET/POST folders, DELETE/PATCH folder

### 2. 批量操作
- 前端多选模式（勾选）
- 底部操作栏：批量删除、移动到文件夹、批量标签
- API: POST /api/assets/batch

### 3. 标签系统
- 利用 tags JSONB 字段
- 标签云显示、标签筛选
- API: GET/POST /api/tags

### 4. 拖拽上传
- react-dropzone 集成
- 拖入高亮、上传进度

### 5. 自定义分类
- 预设分类：CHARACTER, SCENE, STORYBOARD, GENERAL, PROP, MUSIC, SCRIPT, EFFECT, BACKGROUND, REFERENCE
- 用户自定义分类（可增删改）
- API: GET/POST /api/categories, PATCH/DELETE /api/categories/{id}
