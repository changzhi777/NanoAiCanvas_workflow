# 应用管理模块 - 执行计划

## 任务描述
渠道商管理中增加应用管理,主要各个具体应用模块具体调用的模型(可以多个)实现单独配置和管理

## 需求确认
| 项目 | 选择 |
|------|------|
| 持久化 | 前端 localStorage + 后端 API |
| 应用模块 | 全部 6 个模块 (Storyboard/Image/Voice/Dialogue/Text/RealtimeVoice) |
| 模型选择 | 多模型同时启用（负载均衡） |

## 文件结构

```
src/
├── app/admin/apps/
│   └── page.tsx              # 应用管理主页面
├── components/admin/apps/
│   ├── AppConfigCard.tsx    # 单个应用配置卡片
│   ├── ModelSelector.tsx    # 模型选择器组件
│   └── index.ts
├── lib/api/
│   └── apps-api.ts          # 应用配置 API
└── stores/
    └── appsConfigStore.ts   # 应用配置状态管理
```

## 实施步骤

### Step 1: 创建应用配置类型定义
- 定义 6 个应用模块的配置结构
- 模型选择为多选模式

### Step 2: 创建 Zustand store
- 应用配置状态管理
- localStorage 持久化
- 后端 API 同步

### Step 3: 创建 API 接口 (apps-api.ts)
- getAppsConfig() - 获取应用配置
- saveAppsConfig() - 保存应用配置

### Step 4: 创建 ModelSelector 组件
- 多选模型列表
- 渠道商筛选
- 搜索功能

### Step 5: 创建 AppConfigCard 组件
- 应用信息展示
- 模型选择器集成
- 启用/禁用开关

### Step 6: 创建应用管理主页面
- 6 个应用卡片网格布局
- 统一配置入口

### Step 7: 集成到管理后台
- AdminSidebar 添加导航入口
- App.tsx 添加路由

## 后端 API

| 接口 | 方法 | 说明 |
|------|------|------|
| `/v2/admin/apps/config` | GET | 获取应用配置 |
| `/v2/admin/apps/config` | POST | 保存应用配置 |
