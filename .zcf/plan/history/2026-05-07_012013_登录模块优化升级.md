# 登录模块优化升级

## 任务概述
针对登录模块进行全面优化和升级，涵盖6个功能模块。

## 模块1 - 基础修复
- 删除冗余 authStore.ts，统一使用 remoteStore.ts
- 拆分 AuthDialog.tsx 为 AuthDialog + UserSettingsDialog + LoginButton
- 添加后端 logout API（清除 Redis session）
- 统一 login/register 请求协议

## 模块2 - 安全加固
- 登录限流：5次失败锁定15分钟（Redis计数）
- 前端 Token 自动刷新（401时用refresh_token续期）

## 模块3 - 忘记密码
- User模型添加 reset_token/reset_token_expires
- POST /auth/forgot-password（生成token+发邮件）
- POST /auth/reset-password（验证token+重置密码）
- 邮件服务（SMTP）
- 前端忘记密码流程UI

## 模块4 - 管理员审核注册
- User模型添加 status（pending/approved/rejected）
- 注册后 status=pending，login时检查status
- 管理员审批API（GET pending / POST approve / POST reject）
- 管理员审批页面
- 前端审核状态提示

## 模块5 - 新用户默认500积分
- 注册（或审批通过）时自动创建 PointsAccount + grant 500

## 模块6 - 邮箱输入优化
- 邮箱输入框拆分：Input（@前缀）+ Select（@nanoai.fun / @qq.com）

## 执行顺序
模块1 → 模块2 → 模块3+4+5 → 模块6
