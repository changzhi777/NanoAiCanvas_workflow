# 聊天富媒体扩展 — 计划

**创建时间**: 2026-05-09 01:52:38
**任务**: 即时聊天支持图片/视频/音频附件 + 提示词文本 + 预览 + 保存到资产库

---

## 方案：Message attachments JSONB + 文件上传到磁盘

### 步骤清单

#### 后端 (backend/)

**S1. Message 模型扩展** — `app/models/conversation.py`
- 新增 `message_type` Column(String(20), default="text")
- 新增 `attachments` Column(JSONB, default=list)
- 运行 ALTER TABLE 添加列

**S2. 文件上传服务** — `app/api/chat.py` 新增端点
- `POST /api/chat/upload` — multipart 上传，按类型保存到 `chat-uploads/{type}/{uuid}.{ext}`
- 图片: 限制 10MB，支持 jpg/png/gif/webp
- 视频: 限制 100MB，支持 mp4/webm
- 音频: 限制 50MB，支持 mp3/wav/ogg
- 返回 `{url, thumbnail_url, name, type}`

**S3. 静态文件挂载** — `app/main.py`
- `StaticFiles(directory="chat-uploads")` 挂载到 `/chat-uploads/`
- nginx 也配置 location 指向同一目录

**S4. 更新消息处理** — `app/api/chat.py`
- `_handle_chat_message`: payload 新增 message_type + attachments 字段
- msg_data 返回时包含 attachments 和 message_type
- REST `get_messages` 返回也包含 attachments

**S5. 保存到资产库端点** — `app/api/chat.py` 新增
- `POST /api/chat/save-attachment` — 接收 {url, type, name, prompt, thumbnail_url}
- 创建 Asset 记录，关联当前用户
- 返回 asset_id

#### 前端 (src/)

**S6. 类型更新** — `src/lib/api/chat-api.ts`
- ChatMessage 增加 message_type, attachments 字段
- 新增 Attachment, MessageType 类型
- 新增 uploadFile, saveAttachmentToAssets API 函数

**S7. WebSocket 更新** — `src/hooks/useChatSocket.ts`
- sendMessage 支持传递 message_type 和 attachments

**S8. chatStore 更新** — `src/stores/chatStore.ts`
- updateConvLastMessage 处理 attachments（预览摘要显示 [图片] [视频] 等）

**S9. ChatDialog UI 大改造** — `src/components/ui/ChatDialog.tsx`
- 输入区: 添加附件按钮（Paperclip 图标）→ 弹出选择器（上传文件 / 从资产库选择）
- 消息渲染: 根据 message_type 渲染不同内容
  - text: 纯文本（现有）
  - image: 图片缩略图 + 点击放大
  - video: 视频播放器控件
  - audio: 音频播放器控件
  - mixed: 文本 + 多附件
- 每个附件: 显示 prompt 文本 + 保存按钮（存入资产库）+ 下载按钮
- 附件预览区: 发送前显示待发送的附件列表

**S10. 资产库选择器组件** — `src/components/ui/AssetPicker.tsx`
- 弹出 Dialog 列出当前用户的资产
- 按类型筛选（image/video/audio）
- 点击选中，返回 asset 信息
