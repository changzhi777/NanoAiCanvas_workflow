# TVC 节点精简与工作流配置管理

## 任务概述
TVC 节点去掉 minimax 选项，精简节点面板，增加后台工作流配置管理，前端属性面板增强模型选择。

## Phase 1：数据库 + 后端 API
1. 新建 `tvc_workflow_configs` 表（scope 区分 global/user）
2. CRUD API：GET 全局配置、GET/PUT 用户配置、PUT 管理员全局配置

## Phase 2：后端引擎读配置
3. `execute_tvc` 读配置（用户 > 全局 > 硬编码）
4. `_breakdown_shots` 预留 AI 分析接口

## Phase 3：前端精简节点
5. 删除 `tvc_minimax`，默认改 `tvc_deep`
6. 节点移除 select 下拉框
7. 模板默认值更新

## Phase 4：前端属性面板 + 配置同步
8. 属性面板：基础配置（展开）+ 模型选择（折叠）
9. API 封装 getTvcConfig / saveTvcConfig
10. 提交任务时带配置，成功后异步保存

## Phase 5：管理后台
11. TVC 配置管理页：每步模型选择 + system prompt 编辑
12. 侧边栏入口

## 优化决策
- 属性面板分组折叠（基础/模型）
- 配置在提交任务时同步，非实时
- 管理后台含 prompt 编辑
- 单表 scope 区分 global/user
- Step 3 AI 分析留 v2
