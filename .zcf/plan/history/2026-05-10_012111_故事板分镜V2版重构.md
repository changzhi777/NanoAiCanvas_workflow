# 故事板分镜V2版工作流重构计划

**创建时间**: 2026-05-09 20:24
**目标**: 重构故事板分镜工作流，从线性流程升级为剧本生成→多节点并行执行架构

---

## 工作流拓扑

```
[故事板分镜V2版] ──→ [分镜头参考图] (四/六/九宫格, 1:1, 2K/4K)
                ──→ [人物角色设计图] (16:9, 3站姿+2特写+2套服饰)
                ──→ [场景设计图] (16:9, 无人物)
                ──→ [分镜头脚本表格] (文本展示)
```

## 执行阶段

### 阶段1: 后端 - 剧本生成接口

**文件**: `backend/app/api/v2/glm_proxy.py`

1. 新增 `POST /api/glm/screenplay` 端点
   - 输入: `{ premise, shot_count, style, quality, model, temperature }`
   - 输出: `{ title, characters[], scenes[], shots[], dialogue[], script_table[] }`
2. 新增 `SCREENPLAY_PROMPT` 系统提示词
   - 要求 GLM 一次性生成: 故事标题、角色描述+生图提示词、场景描述+生图提示词、分镜头+生图提示词、对白、脚本表格
3. 新增 `ScreenplayRequest` Pydantic 模型
4. 复用 `_repair_json` + `_extract_shots_from_content` 做解析

### 阶段2: 前端 - 共享类型与API

**文件**: `src/components/nanoai-workflow/nodes/StoryboardV2.shared.ts` (新建)

1. 定义 `ScreenplayData` 接口 (title, characters, scenes, shots, dialogue, script_table)
2. 定义 `CharacterDesign` 接口 (name, description, pose_prompts, expression_prompts, outfit_prompts)
3. 定义 `SceneDesign` 接口 (name, description, prompt)
4. 定义 `ScriptTableEntry` 接口 (shot_number, description, dialogue, camera, mood, duration)
5. 导出 `generateScreenplay()` 函数调用后端
6. 导出 `DEFAULT_V2_PARAMS` 常量

### 阶段3: 前端 - StoryboardV2Node 组件

**文件**: `src/components/nanoai-workflow/nodes/StoryboardV2Node.tsx` (新建)

1. 节点组件: 输入框 + 优化参数 + 执行按钮
2. 执行逻辑: 调用 `generateScreenplay()` 生成剧本
3. 结果存储: 将完整剧本数据存入 `node.data.result`
4. 步骤动画: 复用 `TaskStepAnimation`
5. 节点尺寸: CardNode 样式，宽度约 280px

### 阶段4: 前端 - 分镜头参考图节点

**文件**: `src/components/nanoai-workflow/nodes/ShotRefImageNode.tsx` (新建)

1. 从上游 StoryboardV2Node 读取 `shots[]` 数据
2. 按四/六/九宫格模式，为每个 shot 调用 SkillQueueAdapter 生图 (1:1, 2K/4K)
3. 实时推送每张完成的图片到 result
4. 属性面板: 缩略图上下排列 + 提示词 + 参数(时间/模型/作者)
5. 九宫格合成选项 (可选)

### 阶段5: 前端 - 人物角色设计图节点

**文件**: `src/components/nanoai-workflow/nodes/CharacterDesignImageNode.tsx` (新建)

1. 从上游读取 `characters[]` 数据
2. 为每个角色的每个视角(3站姿+2特写+2服饰)调用 SkillQueueAdapter 生图 (16:9)
3. 实时推送图片
4. 属性面板: 同分镜头参考图格式

### 阶段6: 前端 - 场景设计图节点

**文件**: `src/components/nanoai-workflow/nodes/SceneDesignImageNode.tsx` (新建)

1. 从上游读取 `scenes[]` 数据
2. 为每个场景调用 SkillQueueAdapter 生图 (16:9, 提示词确保无人物)
3. 属性面板: 同分镜头参考图格式

### 阶段7: 前端 - 分镜头脚本表格节点

**文件**: `src/components/nanoai-workflow/nodes/StoryboardScriptTableNode.tsx` (新建)

1. 从上游读取 `script_table[]` + `dialogue[]` 数据
2. 表格展示: 镜头号 | 描述 | 对白 | 镜头角度 | 氛围 | 时长
3. 每行关联对应的缩略图 (从分镜头参考图节点获取)
4. 纯文本/表格展示，不生图

### 阶段8: 前端 - Store + 注册 + 模板

1. `WorkflowNodeType` 枚举新增 5 个类型
2. `executeNode` 新增 5 个 case
3. `nodes/index.ts` 注册 5 个新组件
4. 新建模板 `storyboard-v2-workflow` (6节点 + 4条扇出边)
5. `WorkflowPropertiesPanel` 新增各节点属性面板
