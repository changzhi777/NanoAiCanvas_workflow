# 修复 TVC 文案节点中文输入问题

## 上下文
TVC 文案/剧本节点的 textarea 无法输入中文。IME 候选窗出现但文字无法上屏。

## 根因分析（两层）
1. **全局 keydown 拦截**：NanoaiWorkflowCanvas.tsx 全局键盘监听器未检查 `isComposing`，IME 按键被快捷键 `preventDefault()` 吞掉
2. **React 受控输入 + IME 冲突**：Zustand `updateNodeParams` 每次 onChange 触发 store 更新 → 组件重渲染 → React 重设 `textarea.value` 为 store 旧值 → IME 组合文本被清空

## 修改清单

### hooks/useIMETextarea.ts（新增）
- IME 兼容 hook，composition 期间用本地 draft state 缓冲
- composition 结束后一次性同步到外部 store

### nodes/TvcScriptNode.tsx
- 接入 useIMETextarea hook
- textarea value 改为 `ime.value`（draft/state 自动切换）
- 清理未使用的 GLM_CONFIG import 和冗余 API 参数

### nodes/StoryboardV2Node.tsx
- 同步接入 useIMETextarea hook

### NanoaiWorkflowCanvas.tsx
- 全局 keydown 添加 `isComposing` / `keyCode === 229` 守卫

### lib/api/tvc-api.ts
- API 路径 `/api/glm/tvc-script` → `/api/glm/screenplay`（404 修复）
- 清理 GenerateScriptParams 冗余字段

### e2e/chinese-input-ime.spec.ts（新增）
- 5 个测试用例，覆盖 IME guard、draft state、快捷键兼容

## 测试结果
