# 管理员登录30天保持

## 问题
管理员进入后台管理总是提示"登录已过期，请重新登录"

## 根因
- `ACCESS_TOKEN_EXPIRE_MINUTES = 30`，access token 30分钟过期
- `REFRESH_TOKEN_EXPIRE_DAYS = 7`，refresh token 仅7天
- 管理员默认 `remember_me=false`，Redis session 仅7天 TTL
- 前端 refresh 失败 → 401 → 显示"登录已过期"

## 方案
后端识别管理员角色，自动升级 session 和 token 有效期为30天

## 改动文件
1. `backend/app/core/security.py` — create_refresh_token 支持 expires_delta
2. `backend/app/api/auth.py` — login/refresh 检测管理员，强制30天
