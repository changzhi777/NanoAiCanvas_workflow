# AI作图功能实现计划

**创建时间**: 2026-05-06
**任务**: 为 nano2 页面添加 AI作图 功能（结构化模板 + garden-skills 本地生图）

## 需求确认

- **功能定位**: B - 结构化模板（18 大类、80+ 模板）
- **交互方式**: A - 完全表单式（每字段下拉/输入）
- **出图方式**: C - garden-skills 本地生图脚本（Mode A）
- **增强需求**: 前置对话使用文本模型自动选择模板

```
    │                                    │       │   └── prompt_builder.py

```

## 技术要点

1. **Skill 扩展机制**: 每个 skill 是独立目录，skill_loader.py 自动扫描注册
2. **异步任务**: 使用 FastAPI BackgroundTasks + Redis 存储状态
3. **模板结构**: 每个模板 JSON 包含 id/name/category/fields 字段
4. **对话推荐**: LLM 分析用户需求，推荐最合适的模板分类
