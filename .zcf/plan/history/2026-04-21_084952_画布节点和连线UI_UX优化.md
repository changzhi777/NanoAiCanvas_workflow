---

### 步骤 7：性能优化
**文件**: `src/styles/node-enhanced.css` 和 `src/styles/edge-enhanced.css`

**优化措施**:
1. 节点和连线添加 `will-change: transform, opacity`
2. 使用 CSS transform 代替 width/height 动画
3. 限制动画节点数量（超过 30 个节点时降低动画质量）
4. 使用 `content-visibility: auto` 优化渲染

**预期结果**: 50 个节点时保持 60fps

---

## 技术细节

### 节点样式类设计
```css
/* 浅色渐变背景 */
.node-glass-gradient {
  background: linear-gradient(135deg, rgba(33,150,243,0.08) 0%, rgba(33,150,243,0.03) 100%);
  backdrop-filter: blur(20px);
  box-shadow: 0 20px 60px rgba(0,0,0,0.3), 0 8px 24px rgba(0,0,0,0.2);
}

/* 左侧彩色竖条 */
.node-border-stripe {
  position: relative;
}
.node-border-stripe::before {
  content: '';
  position: absolute;
  left: 0;
  top: 0;
  bottom: 0;
  width: 4px;
  background: linear-gradient(180deg, #2196F3 0%, #1976D2 100%);
  border-radius: 8px 0 0 8px;
}
```

### 连线动画设计
```css
/* 虚线流动动画 */
.edge-flow {
  stroke-dasharray: 10, 10;
  animation: dash-flow 1s linear infinite;
}

@keyframes dash-flow {
  to {
    stroke-dashoffset: -20;
  }
}
```

### Handle 样式设计
```tsx
<div className="w-3 h-3 rounded-sm bg-blue-500 hover:scale-125 hover:w-4 hover:h-4 transition-all duration-200" />
```
