### 步骤 2：扩展 API 配置字段
文件: `src/app/admin/system/page.tsx`

新增配置项：
1. **节点超时时间** (timeout) - 默认 60000ms
2. **节点重试次数** (retryCount) - 默认 3
3. **最大并发节点数** (maxConcurrent) - 默认 5
4. **节点池大小** (nodePoolSize) - 默认 10
5. **启用节点缓存** (nodeCacheEnabled) - 默认 true
6. **节点执行模式** (executionMode) - sync/async

### 步骤 3：添加配置持久化
- 使用 localStorage 保存配置
- 添加加载和保存功能

### 步骤 4：创建节点配置类型定义
文件: `src/types/workflow-node-config.ts` (新建)

```typescript
export interface NodeExecutionConfig {
  timeout: number;           // 节点超时时间(ms)
  retryCount: number;        // 重试次数
  maxConcurrent: number;     // 最大并发数
  nodePoolSize: number;       // 节点池大小
  nodeCacheEnabled: boolean;  // 是否启用缓存
  executionMode: 'sync' | 'async';  // 执行模式
}
```
