# wmtools 双引擎集成实施计划

> 研究依据：`隐形水印研究.md` 维度十八（WAM 实测四场景全胜）/ 十九（Video Seal 实测三项 100%）
> 目标：wmtools 升级双引擎——L1 频域轻量（全 CPU 秒级）+ L2 深度（WAM 图像 / Video Seal 视频）

## 架构
```
scripts/wmtools/engines/
├── __init__.py            引擎注册 + 可用性探测
├── base.py               Engine 协议：name/tier/domain/available/embed/extract
├── freq.py               L1（包装现有 wm_image/wm_video，零语义变化）
├── wam_engine.py         L2 图像（WAM：MPS→CPU fallback；normalize 域/sigmoid/CPU 投票三坑封装）
└── videoseal_engine.py   L2 视频（Video Seal：PyAV + 60 帧分段 + 恒 CPU + 音轨混回）
vendor/（gitignore）        watermark-anything / videoseal 仓库 + 权重
setup_engines.sh           幂等装 L2（本地缓存优先，否则 clone/wget）
```

## 关键决策
- canonical ID 恒为 8B；容量适配封装在各引擎 pack/unpack：
  - freq: RS(20,8) 20B
  - WAM: 32-bit 精简 ID（proj8b+seq24b）→ registry 关联取全 ID
  - VideoSeal: 32B = magic4B + ID8B + ID反码8B + CRC32(id)4B + 固定图案8B（多重校验）
- `--tier light|deep`（默认 light）：deep = L1+L2 双嵌（快速核验 + 强抗性并存）
- 检测双引擎并行，报告 layers 按引擎键 + 命中 engine 可溯
- 设备：WAM MPS 失败自动 fallback CPU；VideoSeal 恒 CPU（实测 MPS 段错误）
- vendor/数据不进 git；引擎缺失时 CLI 明确指引 setup_engines.sh
