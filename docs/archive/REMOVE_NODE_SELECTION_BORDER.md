# 节点选中外框移除说明

> **版本**: v2.1.1
> **更新日期**: 2026-04-15
> **修改类型**: UI视觉优化

---

## 🐛 用户反馈

"点击节点时卡片不要显示外框边缘"

---

## 🎯 修改内容

### 移除的样式

#### 1. React Flow 节点选中外框

**位置**: `src/styles/globals.css:149-151`

**修改前**：
```css
.react-flow__node.selected {
  @apply ring-2 ring-primary;
}
```

**修改后**：
```css
.react-flow__node.selected {
  /* 移除选中状态的外框边缘 - 用户要求不显示 */
  /* @apply ring-2 ring-primary; */
}
```

**效果**：
- ❌ 移除：2px 主题色外框（ring-2）
- ❌ 移除：主题色边框（ring-primary）

---

#### 2. 卡片节点选中外框和动画

**位置**: `src/styles/globals.css:410-416`

**修改前**：
```css
.card-node.selected {
  transform: translate3d(0, 0, 0) scale(0.5);
  box-shadow:
    0 0 0 2px hsl(var(--primary)),        /* ← 2px外框线 */
    0 0 20px hsl(168 70% 45% / 0.5),     /* ← 强发光 */
    0 10px 30px -5px hsl(0 0% 0% / 0.3);
  animation: select-pulse 2s ease-in-out infinite;  /* ← 脉冲动画 */
}
```

**修改后**：
```css
.card-node.selected {
  transform: translate3d(0, 0, 0) scale(0.5);
  /* 移除外框边缘，保留阴影 */
  box-shadow:
    /* 0 0 0 2px hsl(var(--primary)), */   /* ✗ 移除外框 */
    0 0 20px hsl(168 70% 45% / 0.3),      /* ✓ 减弱发光 */
    0 10px 30px -5px hsl(0 0% 0% / 0.3);
  /* animation: select-pulse 2s ease-in-out infinite; */  /* ✗ 移除动画 */
}
```

**效果**：
- ❌ 移除：2px 外框线
- ❌ 移除：脉冲动画
- ✅ 保留：发光阴影（从50%减弱到30%）
- ✅ 保留：基础深度阴影

## 💡 设计理念

### 现代UI设计趋势

**传统设计**：
- 选中 = 强边框 + 动画
- 多层视觉反馈
- 高对比度

**现代设计**：
- 选中 = 微妙阴影 + 柔和发光
- 单层视觉反馈
- 低干扰

**示例对比**：

| 应用 | 选中效果 |
|------|---------|
| **Figma** | 轻微发光，无边框 |
| **Miro** | 柔和阴影，无边框 |
| **Notion** | 背景色变化，无边框 |
| **v2.1.0** | 外框 + 动画 ← 传统 |
| **v2.1.1** | 柔和发光 ← 现代 ✅ |
