# 右侧面板智能显示改进说明

> **版本**: v2.0.7
> **更新日期**: 2026-04-15
> **改进类型**: UX交互优化

---

## 🎯 改进概述

右侧属性面板现在采用**智能显示机制**：只在选中节点时才从右侧滑出，未选中时完全不显示。进一步优化画布空间利用率。

---

## ✨ 改进内容

### 1. 智能显示逻辑

**改进前**：
- ❌ 始终显示在右侧
- ❌ 未选中时显示占位提示"选择一个节点以查看属性"
- ❌ 占用256px宽度的空间

**改进后**：
- ✅ 未选中节点时完全不显示（返回null）
- ✅ 选中节点时面板从右侧滑出
- ✅ 未选中时0px占用，最大化画布空间

### 2. 自动展开功能

**改进前**：
- 用户手动点击展开按钮
- 需要额外操作

**改进后**：
- 选中节点时自动展开面板
- 无需额外操作，交互更流畅

### 3. 状态智能重置

**改进前**：
- 切换节点后可能保留之前的编辑状态
- 可能保留折叠状态

**改进后**：
- 切换节点时自动重置为展开状态
- 切换节点时自动退出编辑模式
- 确保每次选中节点都是"干净"的状态

---

## 🎨 交互流程

### 场景1：首次选中节点

```
1. 用户点击画布上的节点
   ↓
2. 节点被选中（高亮显示）
   ↓
3. 右侧面板从右侧滑出（325ms动画）
   ↓
4. 显示节点完整属性信息
```

### 场景2：切换节点

```
1. 用户点击另一个节点
   ↓
2. 原节点取消选中
   ↓
3. 右侧面板内容更新
   ↓
4. 自动展开（如果之前折叠）
   ↓
5. 退出编辑模式（如果之前在编辑）
   ↓
6. 显示新节点属性
```

### 场景3：取消选择

```
1. 用户点击画布空白处
   ↓
2. 节点取消选中
   ↓
3. 右侧面板完全消失（不占用空间）
   ↓
4. 画布空间最大化
```

## 🔧 技术实现

### 核心代码

```typescript
export default function PropertiesPanel() {
  const selectedNodeId = selectedNodes[0]
  const hasSelection = selectedNodeId !== undefined
  const currentNode = allNodes.find((node) => node.id === selectedNodeId)

  // 选中节点时自动展开面板，重置状态
  useEffect(() => {
    if (currentNode) {
      setNodeData(currentNode.data)
      setIsCollapsed(false)  // 自动展开
      setEditing(false)       // 退出编辑模式
    }
  }, [currentNode])

  // 没有选中节点时完全不显示
  if (!hasSelection) {
    return null  // 返回null而不是占位组件
  }

  // 有选中节点时显示面板
  return (/* 面板组件 */)
}
```

### 关键改进点

**1. 条件渲染**
```typescript
// 改进前：显示占位提示
if (!hasSelection) {
  return <PlaceholderPanel />
}

// 改进后：完全不渲染
if (!hasSelection) {
  return null
}
```

**2. 状态自动重置**
```typescript
useEffect(() => {
  if (currentNode) {
    setNodeData(currentNode.data)
    setIsCollapsed(false)  // 新增：自动展开
    setEditing(false)       // 新增：退出编辑
  }
}, [currentNode])
```

**3. 性能优化**
- 不使用的组件完全不渲染（返回null）
- React不会在DOM中添加任何元素
- 节省内存和渲染开销

## 🎯 设计原则应用

### KISS（保持简单）
- ✅ 逻辑简单：有节点就显示，没节点就隐藏
- ✅ 交互简单：点击节点即显示，无需额外操作
- ✅ 视觉简单：无节点时画布更清爽

### YAGNI（只实现必要功能）
- ✅ 移除了不必要的占位提示
- ✅ 不需要用户手动展开面板
- ✅ 自动重置状态，减少用户操作

### 用户期望
- ✅ 符合直觉：点击节点就应该显示属性
- ✅ 减少干扰：不需要属性时面板不应该存在
- ✅ 最大化空间：画布是主要工作区域

---

## 🚀 性能提升

### 渲染性能
- **未选中时**：完全不渲染，节省内存
- **选中时**：只有必要的组件在DOM中
- **切换时**：平滑动画，325ms过渡

### 内存占用
```
改进前：
├── PropertiesPanel (始终渲染)
│   ├── PlaceholderPanel (未选中时)
│   └── FullPanel (选中时)

改进后：
├── PropertiesPanel (选中时渲染)
│   └── FullPanel
└── null (未选中时)
```

## 📝 使用说明

### 正常使用流程

1. **查看节点属性**
   - 点击任意节点
   - 右侧面板自动滑出
   - 显示节点完整属性

2. **编辑节点属性**
   - 在面板中点击编辑按钮
   - 修改属性内容
   - 点击保存按钮

3. **折叠面板**
   - 点击面板顶部折叠按钮
   - 面板收起为64px宽信息条
   - 仍可查看节点关键信息

4. **切换节点**
   - 点击另一个节点
   - 面板自动展开（如果之前折叠）
   - 显示新节点属性
   - 编辑状态自动重置

5. **关闭面板**
   - 点击画布空白处取消选择
   - 面板完全消失
   - 画布空间最大化
