## 🔧 技术实现

### 核心代码结构

```typescript
export default function NodeTemplatesPanel() {
  const [isCollapsed, setIsCollapsed] = useState(false)

  // 收起状态：只显示折叠按钮
  if (isCollapsed) {
    return (
      <div className="fixed left-0 top-0 bottom-0 z-40 flex items-center">
        <button onClick={handleToggleCollapse}>
          <ChevronRight />  // 向右箭头
        </button>
      </div>
    )
  }

  // 展开状态：显示完整内容
  return (
    <div className="w-64 bg-card/80 backdrop-blur-md">
      {/* 头部 */}
      {/* 模板列表 */}
      {/* 底部折叠按钮 */}
    </div>
  )
}
```

### CSS类说明

| 类名 | 用途 | 效果 |
|------|------|------|
| `bg-card/80` | 面板背景 | 80%不透明度 |
| `backdrop-blur-md` | 玻璃态 | 12px模糊 |
| `border-border/50` | 边框 | 50%不透明 |
| `transition-all` | 过渡动画 | 所有属性平滑过渡 |
| `duration-325` | 动画时长 | 325ms |
| `ease-in-out` | 缓动函数 | 平滑进出 |

### 响应式交互

```typescript
// 悬停状态管理
const [isHovering, setIsHovering] = useState(false)

// 应用到按钮
onMouseEnter={() => setIsHovering(true)}
onMouseLeave={() => setIsHovering(false)}

// 条件样式
className={cn(
  'hover:scale-110',           // 悬停放大
  isHovering && 'scale-105'     // 额外缩放反馈
)}
```

## 🎯 使用指南

### 如何收起面板

#### 方法1：点击折叠按钮
1. 找到面板底部的圆形折叠按钮（◀）
2. 点击按钮
3. 面板平滑收起，只显示折叠条

#### 方法2：使用快捷键
1. 按 `F2` 键
2. 面板切换收起/展开状态

#### 方法3：使用边缘触发器
1. 将鼠标移到屏幕左边缘
2. 等待200ms
3. 面板会自动展开

### 如何展开面板

#### 方法1：点击折叠按钮
1. 找到左边缘的折叠按钮（▶）
2. 点击按钮
3. 面板平滑展开，显示所有节点模板

#### 方法2：使用快捷键
1. 按 `F2` 键
2. 面板切换展开/收起状态

#### 方法3：使用边缘触发器
1. 将鼠标移到屏幕左边缘
2. 等待200ms
3. 面板会自动展开（如果已收起）

## 🐛 故障排除

### Q: 面板收起后无法展开？

**A**: 检查以下几点：
1. 点击左边缘的折叠按钮（▶）
2. 或按 `F2` 快捷键
3. 或将鼠标移到左边缘等待200ms

### Q: 透明效果不明显？

**A**: 确保以下设置：
1. `backdrop-blur-md`已启用
2. 面板后面有内容可以透出
3. 浏览器支持`backdrop-filter`

### Q: 动画卡顿？

**A**: 优化建议：
1. 检查是否有其他性能问题
2. 使用浏览器DevTools检查FPS
3. 确保GPU加速已启用
