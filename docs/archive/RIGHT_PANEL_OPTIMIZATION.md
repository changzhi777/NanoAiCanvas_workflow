## 🔧 技术实现

### 核心代码结构

```typescript
export default function PropertiesPanel() {
  const [isCollapsed, setIsCollapsed] = useState(false)

  // 收起状态：显示节点基本信息
  if (isCollapsed && currentNode) {
    const NodeIcon = nodeIconMap[currentNode.data.type] || nodeIconMap.task

    return (
      <div className="w-16 bg-card/80 backdrop-blur-md">
        {/* 折叠按钮 */}
        <button onClick={handleToggleCollapse}>
          <ChevronLeft />
        </button>

        {/* 节点图标 */}
        <NodeIcon className="text-2xl" />

        {/* 节点标题 */}
        <p className="text-xs line-clamp-2">
          {currentNode.data.label}
        </p>

        {/* 状态徽章 */}
        <Badge>{status}</Badge>
      </div>
    )
  }

  // 展开状态：显示完整内容
  return (
    <div className="w-64 bg-card/80 backdrop-blur-md">
      {/* 头部 */}
      <div className="flex justify-between">
        <h2>属性面板</h2>
        <button onClick={handleToggleCollapse}>
          <ChevronRight />
        </button>
        {/* 编辑和删除按钮 */}
      </div>

      {/* 属性内容 */}
    </div>
  )
}
```

### CSS类说明

| 类名 | 用途 | 效果 |
|------|------|------|
| `bg-card/80` | 面板背景 | 80%不透明度 |
| `backdrop-blur-md` | 玻璃态 | 12px模糊 |
| `border-border/50` | 边框 | 50%不透明 |
| `transition-all` | 过渡动画 | 所有属性平滑过渡 |
| `duration-325` | 动画时长 | 325ms |
| `ease-in-out` | 缓动函数 | 平滑进出 |
| `line-clamp-2` | 文本截断 | 最多显示2行 |

### 节点图标映射

const nodeIconMap: Record<string, React.ComponentType<{ className?: string }>> = {

## 🐛 故障排除

### Q: 面板收起后无法展开？

**A**: 检查以下几点：
1. 点击右边缘信息条顶部的折叠按钮（◀）
2. 或按 `F1` 快捷键
3. 确保已选中节点（否则不会显示折叠状态）

### Q: 收起状态没有显示节点信息？

**A**: 确保以下条件：
1. 已选中一个节点
2. 节点数据完整（有label和status）
3. currentNode数据存在

### Q: 透明效果不明显？

**A**: 确保以下设置：
1. `backdrop-blur-md`已启用
2. 面板后面有内容可以透出
3. 浏览器支持`backdrop-filter`

## 🎯 设计原则应用

### KISS（保持简单）
- ✅ 操作直观：点击顶部按钮即可收起
- ✅ 视觉清晰：折叠按钮明确可见
- ✅ 交互简单：单一操作即可完成

### DRY（避免重复）
- ✅ 使用与左侧面板相同的动画时长
- ✅ 复用isCollapsed状态管理逻辑
- ✅ 保持快捷键系统一致（F1）

### YAGNI（只实现必要功能）
- ✅ 不添加复杂的嵌套动画
- ✅ 不添加多余的装饰元素
- ✅ 只实现用户选择的功能
