# 右侧属性面板默认折叠功能说明

> **版本**: v2.1.2
> **更新日期**: 2026-04-15

---

## 🎯 功能概述

根据用户通过一一问答选择的设计方案，右侧属性面板从"选中时才显示"改为"默认折叠显示"，始终可见且易于访问。

---

## ✨ 您的设计选择

### 第一轮问答：默认显示方式

**您的选择**: 📍 **显示折叠状态**

**选项对比**：
| 选项 | 效果 | 用户选择 |
|------|------|---------|
| 始终显示完整面板 | 256px宽，显示完整属性 | ✗ |
| 显示折叠状态 | 64px宽折叠条 | ✅ |
| 隐藏但有触发器 | 完全隐藏，鼠标移入显示 | ✗ |

**理由**：
- 始终可见，不会丢失
- 节省空间（仅64px宽）
- 易于访问

---

### 第二轮问答：收回方式

**您的选择**: 多种方式
- ✅ 点击折叠按钮
- ✅ 按快捷键（F1）
- ✅ 点击外部

---

### 第三轮问答：再次展开

**您的选择**: 📍 **移到右边缘**

**理由**：
- 符合现代UI习惯
- 类似左侧面板的边缘触发器
- 直观易用

## 🔧 技术实现

### 核心状态

```typescript
const [isCollapsed, setIsCollapsed] = useState(true) // 默认折叠
const [isHovering, setIsHovering] = useState(false)
```

**关键变化**：
- `isCollapsed` 初始值：`false` → `true`
- 新增 `isHovering` 状态
- 移除 `!hasSelection return null` 逻辑

---

### 边缘触发器

```tsx
{/* 4px宽的触发区域 */}
<div
  onMouseEnter={() => {
    if (!hasSelection) {
      setIsHovering(true) // 触发悬停效果
    }
  }}
  onMouseLeave={() => {
    setIsHovering(false)
  }}
  className="absolute right-0 top-0 bottom-0 w-4 cursor-pointer"
  onClick={() => {
    setIsCollapsed(false) // 点击展开
  }}
/>
```

**效果**：
- 4px宽的不可见触发区域
- 鼠标移入时折叠条变宽（16px → 20px）
- 点击触发区域展开面板

---

### 折叠状态内容

**未选中节点**：
```tsx
{!hasSelection && (
  <>
    <ChevronRight />  {/* 提示图标 */}
    <p>属性</p>       {/* 提示文字 */}
  </>
)}
```

**已选中节点**：
```tsx
{hasSelection && currentNode && (
  <>
    <NodeIcon />       {/* 节点图标 */}
    <p>节点名称</p>    {/* 节点标题 */}
    <Badge>状态</Badge> {/* 节点状态 */}
  </>
)}
```

---

### 始终渲染

**修改前**：
```typescript
if (!hasSelection) {
  return null  // 完全不渲染
}
```

**修改后**：
```typescript
if (isCollapsed) {
  return <折叠条 />  // 始终渲染折叠条
}
return <完整面板 />     // 展开时渲染完整面板
```

**优势**：
- 组件始终挂载
- 动画效果更好
- 状态切换更流畅

## 🔧 实现细节

### 状态管理

```typescript
// 默认折叠
const [isCollapsed, setIsCollapsed] = useState(true)

// 悬停状态
const [isHovering, setIsHovering] = useState(false)

// 选中节点时自动展开
useEffect(() => {
  if (currentNode) {
    setIsCollapsed(false)
  }
}, [currentNode])
```

---

### 条件渲染逻辑

```typescript
// 折叠状态
if (isCollapsed) {
  return (
    <>
      {/* 边缘触发器 */}
      <触发区域 />
      {/* 折叠条 */}
      <折叠条 />
    </>
  )
}

// 展开状态
return (
  <>
    <完整面板 />
  </>
)
```

---

### F1快捷键支持

**在 `useShortcuts.ts` 中**：
```typescript
// F1: 切换属性面板
if (e.key === 'F1') {
  e.preventDefault()
  dispatch(togglePanel('properties'))
}
```

**注意**：
- 目前使用 `togglePanel('properties')`
- 这个action会切换 `panelOpen.properties` 状态
- 需要确认这个action是否与我们的 `isCollapsed` 状态同步

## 📝 已知问题和限制

### 1. 点击外部关闭

**状态**：未实现

**原因**：
- 需要在Canvas层面添加点击检测
- 可能会干扰画布交互
- 需要谨慎设计

**未来改进**：
- 可以添加一个短暂的延迟
- 或者只在面板展开时响应

---

### 2. togglePanel Action同步

**状态**：需要确认

**问题**：
- 使用F1键调用 `togglePanel('properties')`
- 这个action切换的是Redux的 `panelOpen.properties`
- 而我们的面板使用本地的 `isCollapsed` 状态

**解决方案**：
- 方案A：监听Redux状态变化，同步到本地状态
- 方案B：修改togglePanel action，直接控制折叠状态
- 方案C：使用本地状态，不依赖Redux（当前实现）

**当前选择**：方案C（使用本地状态）
