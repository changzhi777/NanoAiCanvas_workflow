**功能**：

## 🎯 规则执行

### 立即生效的规则

1. **根目录禁止存放**：
   - ❌ 临时 .md 文件（TEMP.md, TODO.md, NOTES.md 等）
   - ❌ 测试文件（*.test.*, *.spec.*）
   - ❌ 临时脚本（temp.*, debug.*, scratch.*）

2. **必须存放在 docs/**：
   - 所有报告和总结 → `docs/reports/`
   - 所有指南文档 → `docs/guides/`
   - 所有功能文档 → `docs/features/`
   - 所有部署文档 → `docs/deployment/`
   - 所有版本文档 → `docs/versions/`
   - 所有归档文档 → `docs/archive/`

3. **自动化检查**：
   - 每次 git commit 前自动运行
   - 检查失败则阻止提交
   - 可手动运行：`pnpm check:root`

### 违规处理

- **第一次**: 友好提醒，指导修复
- **第二次**: 要求修改，拒绝合并 PR
- **第三次**: 更新文档，加强培训
