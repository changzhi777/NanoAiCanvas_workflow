## [2.1.2] - 2026-04-15

### 新增 (Added)
- ✨ **右侧面板默认折叠显示**：64px宽折叠条始终显示
- ✨ **边缘触发器**：鼠标移到右边缘自动展开预览
- ✨ **智能内容显示**：折叠状态根据是否选中节点显示不同内容

### 优化 (Changed)
- 🎯 **默认状态改变**：从"隐藏"改为"折叠"（更易访问）
- 🎯 **展开时机优化**：选中节点时自动展开，取消后保持折叠
- 🎯 **交互方式增强**：支持F1快捷键、点击按钮、点击边缘触发

### 设计实现 (Design)
根据用户通过一一问答选择的设计方案：

**默认显示**：
- 默认状态：64px宽折叠条
- 始终显示在右侧，不会隐藏
- 未选中节点时：显示"属性"提示
- 选中节点时：显示节点信息（图标+标题+状态）

**展开时机**：
- 点击节点时：自动展开，显示完整属性
- 按F1键：切换展开/折叠状态
- 点击折叠按钮：切换展开/折叠状态
- 鼠标移到右边缘：展开预览（悬停时变宽）

**收回方式**：
- 点击折叠按钮（ChevronRight图标）
- 按F1快捷键
- 未来：点击画布空白处（可选）

**再次展开**：
- 鼠标移到右边缘（自动展开预览）
- 点击展开按钮
- 选中节点时自动展开

### 技术细节 (Technical)
- **状态管理**：isCollapsed默认值为true（默认折叠）
- **始终渲染**：不再根据hasSelection返回null
- **边缘触发**：4px宽的触发区域，鼠标移入触发
- **条件渲染**：根据hasSelection显示折叠条中的不同内容
- **悬停效果**：isHovering状态控制折叠条宽度（16px→20px）

### 用户体验改进 (UX)
- ✅ 右侧面板始终可访问（不会完全隐藏）
- ✅ 边缘触发器提供直观的交互方式
- ✅ 默认折叠节省空间（仅64px宽）
- ✅ 选中节点时自动展开（无需手动操作）

## [2.0.9] - 2026-04-15

### 修复 (Fixed)
- 🔧 **快捷键面板开关逻辑**：修复onOpenChange状态设置错误
- 🔧 **导入语句更新**：从toggleShortcutPanel改为setShortcutPanelVisible
- 🔧 **输入框兼容**：添加输入框检测，避免在输入时触发快捷键
- 🔧 **事件处理优化**：确保快捷键只在正确的上下文中触发

### 问题详情 (Issue Details)
**问题描述**：
- 按下?键无法打开快捷键面板
- 面板的打开/关闭状态切换异常

**根本原因**：
```typescript
// 错误的实现（v2.0.8）
onOpenChange={(open) => {
  if (open) {
    dispatch(toggleShortcutPanel())  // 错误：无论open值都调用toggle
  } else {
    dispatch(toggleShortcutPanel())  // 错误：导致状态翻转
  }
}}
```

**修复方案**：
```typescript
// 正确的实现（v2.0.9）
onOpenChange={(open) => {
  dispatch(setShortcutPanelVisible(open))  // 直接设置状态
}}
```

**输入框兼容**：
```typescript
// 检查是否在输入元素中
const target = e.target as HTMLElement
const isInput = target.tagName === 'INPUT' ||
               target.tagName === 'TEXTAREA' ||
               target.isContentEditable

if (!isInput) {
  // 只在非输入状态下触发快捷键
  dispatch(toggleShortcutPanel())
}
```

### 技术细节 (Technical)
- **Redux Action修复**：使用setShortcutPanelVisible替代toggleShortcutPanel
- **事件目标检测**：添加输入元素检测逻辑
- **类型安全**：TypeScript类型断言HTMLElement

### 测试状态 (Testing)
- ✅ TypeScript类型检查通过
- ✅ 生产构建成功
- ✅ ?键快捷键正常工作
- ✅ 输入框中不会误触发

### 文件统计 (Files)
- 修改文件：2个
- 修复行数：3行
- 影响范围：快捷键面板开关逻辑
