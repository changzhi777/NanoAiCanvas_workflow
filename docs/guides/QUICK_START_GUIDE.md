# NanoAI Workflow - 快速开始指南

> 5 分钟上手 AI 工作流编辑器

---

## 🚀 快速启动

### 1. 安装依赖
```bash
pnpm install
```

### 2. 启动开发服务器
```bash
pnpm run dev
```

### 3. 访问应用
打开浏览器访问：http://localhost:3001/

---

## 🎯 5分钟快速教程

### 第一步：创建工作流

1. **切换到 AI 工作流页面**
   - 点击顶部 "AI 工作流" 按钮

2. **添加节点**
   - 从左侧侧边栏点击 "分镜头生成" 节点
   - 节点自动添加到画布中心

3. **设置参数**
   - 点击节点展开内容
   - 输入数据源：`storyboard scene`
   - 选择风格：`写实风格`
   - 选择比例：`16:9（横屏）`
   - 生成数量：`4`

### 第二步：执行生成

1. **点击执行按钮**
   - 点击节点内的 "执行" 按钮
   - 或点击工具栏 "执行工作流" 按钮

2. **查看进度**
   - 节点状态变为 "运行中"
   - 进度条实时显示
   - 生成完成后显示结果

3. **查看结果**
   - 节点底部显示生成的图片
   - 点击图片可下载
   - 点击复制按钮可复制 URL

### 第三步：保存工作流

1. **保存为模板**
   - 点击工具栏 "保存" 按钮
   - 选择 "保存为模板"
   - 输入模板名称：`我的第一个工作流`
   - 点击 "保存模板"

2. **导出工作流**
   - 点击工具栏导出按钮
   - 自动下载 JSON 文件

## 💡 使用技巧

### 技巧 1：快速添加节点
- 点击侧边栏节点卡片（最快）
- 搜索节点名称
- 查看热门/NEW 标签

### 技巧 2：连接节点
- 从右侧输出端口拖拽到左侧输入端口
- 系统自动检测类型匹配
- 端口颜色对应类型：
  - 🔵 蓝色 - 文本
  - 🟣 紫色 - 图片
  - 🟢 绿色 - 音频
  - 🟡 黄色 - JSON
  - 🟠 橙色 - 数组

### 技巧 3：管理节点
- 点击节点右上角菜单按钮
- 可复制/删除/重置/导出节点
- 点击标题栏可折叠节点内容

### 技巧 4：版本管理
- 保存版本快照
- 最多保存 10 个版本
- 一键恢复历史版本

## 🐛 常见问题

### Q: 节点执行失败怎么办？
**A:** 
1. 查看节点错误提示
2. 检查参数是否正确
3. 点击 "重试" 按钮
4. 或点击 "重置节点" 清空状态

### Q: 如何清空画布？
**A:** 
1. 点击工具栏红色垃圾桶图标
2. 确认对话框
3. 画布将被清空（不可撤销）

### Q: 导入工作流失败？
**A:** 
1. 确保 JSON 格式正确
2. 检查文件是否损坏
3. 尝试重新导出后再导入

### Q: 深色主题动画卡顿？
**A:** 
1. 检查浏览器性能
2. 关闭其他占用 GPU 的应用
3. 或切换回浅色主题
