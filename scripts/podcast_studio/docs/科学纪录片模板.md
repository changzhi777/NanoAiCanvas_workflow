# 科学纪录片模板（science_doc）🔬

> **一句话**：一个元素/主题 → 旁白脚本（事实核校）→ NB21 手绘图卡静止展示 → H3 插画活化高光 → 速创 TTS 抒情男声 → WAM 逐帧 deep 水印 → ~2.5 分钟科普成片。
> 全链实战验证于《锂 · 会跳舞的金属》（153.3s，产出档案 `scripts/podcast_studio/assets/productions/锂_会跳舞的金属/`）。

**位置**：`scripts/podcast_studio/out/lithium_science/`（模板工具集）｜ **衍生自**：播客图文解说工作流

## 适用场景

儿童/青少年科学科普、化学元素系列、科学实验讲解、发明发现故事。单集 2-3 分钟，可按元素/主题批量复制。

## 标准结构（10 镜 · 150s 预算）

| 镜 | 时长 | 内容 | 呈现 |
|---|---|---|---|
| S0 | 6s | H3 螺旋镜头：主体环绕上升（插画活化英雄镜头） | H3 15s 剪 6s |
| S1-S3 | ~60s | 钩子 / 发现史 / 核心性质 | NB21 图卡静止 + 文字动效 |
| S4-S5 | ~45s | **实验演示 ×2**（含安全角标） | H3 插画活化 或 静止图卡 |
| S6 | ~20s | 原理（方程式/机制示意） | 程序化文字动画（**禁 H3**） |
| S7 | ~20s | 现实应用（数据量化） | 图卡 + 数字滚动 |
| S8 | ~10s | 金句收尾 | 图卡 + 淡入 |

## 生成通道

| 环节 | 通道 | 关键参数/坑 |
|---|---|---|
| 母卡 | NanoBanana2.1 16:9 2K | 统一风格锚 prompt（手绘线稿+水彩+暖纸底+涂鸦）；**NO text** |
| 实验动画 | 速创 H3 15s first_frame | prompt 锁「插画活化」（禁写实化/禁新增元素/禁文字）；**先试片再审** |
| 旁白 TTS | **速创 audio_tts** `Chinese (Mandarin)_Lyrical_Voice` speed 1 | 返回 **tar 包**（mp3+titles 毫秒级字幕）自动解包；MiniMax API/网页声贝不足时此通道不受影响 |
| 音频水印 | WavMark 16-bit（venv：`/tmp/audioseal_venv`，AudioSeal py3.14 硬崩弃用） | registry 关联取全 ID |
| 视频水印 | WAM 逐帧（MPS）+ C2PA | 位级多数投票 + 汉明 ≤2bit 模糊关联 |
| 字幕 | NB21 出图后 titles 直出 + ASS 样式 | FontSize 20 / 边距 40（**30 过大**）；特殊字形 ₂³ 用 Arial Unicode |

## 关键纪律（审查后沉淀）

1. **图卡画面完全静止**：base_frame 一次 resize 缓存零重采样——帧间差分必须 ≈0（连续缩放呼吸=整幅抖动，已翻车一次）
2. **BGM 必须过 demucs 人声复检**：vocals 轨 mean ≤ -28dB 方可用（tech_clean 含女声吟唱 -19.7dB 已翻车两次，移入 `_archive_vocal_contaminated/`）
3. **H3 只用于现象展示**：原理/方程式/数据段禁 H3（物理细节失真）；prompt 必须含「禁新增元素/禁写实化/禁文字」
4. **H3 对 360° 环绕不稳**：螺旋镜头只要求 ~150°，不足靠剪辑承接
5. **口播词与制作注记分离**：`【】[]` 注记绝不进 TTS 文本
6. **事实核校**：科学家归属、年份、数字逐一验证（锂篇修正戴维误记）
7. **特殊字形**：₂/³ 等 Hiragino 缺字 → Arial Unicode
8. **出片后必跑**：wmtools pipeline deep（水印+C2PA+指纹）+ demucs BGM 人声复检

## 一键复刻（锂篇为例）

```bash
cd scripts/podcast_studio/out/lithium_science
python3 gen_cards.py                 # 9 张母卡
python3 tts_chuang_batch.py          # 9 句旁白（速创 TTS）
python3 h3_helix.py                  # H3 螺旋镜头（后台）
python3 assemble_lithium.py          # 总装（静止图卡+H3+字幕+BGM）
cd ../../wmtools
python3 wm_cli.py pipeline <成片> --project <项目名> --tier deep   # 水印+C2PA+指纹
```
