# 作品库

每个子目录 = 一个**自包含作品资产包**（成片 + 音轨 + BGM + 分镜 + 字幕 + 插画 + 制作档案），可独立迁移/复现。

| 作品 | 时长 | 风格 | 完成 |
|---|---|---|---|
| [机器干活人觉醒](./机器干活人觉醒/README.md) | 3:50 | culture | 2026-10-15 |

## 归档规范

```
productions/<作品名>/
├── README.md               # 制作档案（参数/资产/校验和/复现命令）
├── 成片_<解说>_<BGM>_<时长>.mp4
├── 字幕.srt
├── 分镜脚本.json            # 文本 + visual_hint
├── 时间轴.json              # ASR/TTS 实测时间轴
├── 解说音轨_<来源>.mp3       # 若为外部解说（锁定只读）
├── BGM_<曲名>.mp3
└── cards/card_XX.png       # 全部插画原图
```

**纪律**：工作目录 `out/` 随时会被下次生成覆盖 —— 终版产出必须下沉到本目录才算"保存"。
