## 🚀 5分钟快速上手

### 步骤1：了解故事板功能（1分钟）

故事板功能是一个**AI驱动的4步骤向导工具**，可以一键生成：

- ✅ **脚本**：GLM-5自动生成场景和角色
- ✅ **分镜头**：NanoBanana Pro生成场景图片
- ✅ **对白**：GLM TTS生成角色语音
- ✅ **角色设计**：AI生成角色设计图

**使用场景**：
- 短视频脚本创作
- 动画分镜头设计
- 广告创意构思
- 故事板快速原型

---

### 步骤2：打开故事板向导（30秒）

1. 访问 NanoAI 主页
2. 点击"故事板"按钮
3. 故事板向导对话框自动打开

**界面元素**：
```
┌─────────────────────────────────────┐
│  故事板向导                    [×] │
├─────────────────────────────────────┤
│  ① ② ③ ④                          │  ← 步骤指示器
├─────────────────────────────────────┤
│                                     │
│  [步骤内容区域]                     │
│                                     │
├─────────────────────────────────────┤
│  [上一步]    [取消]  [下一步] →     │  ← 操作按钮
└─────────────────────────────────────┘
```

---

### 步骤3：生成脚本（1分钟）

**操作流程**：

1. **输入文案**（必填）
   ```
   示例：一只橘猫在公园里追蝴蝶，被蜜蜂蛰了，
   跑到湖边喝水，遇到了一只友善的金毛犬。
   ```

2. **选择风格**（必填）
   - 卡通风格
   - 写实风格
   - 水彩风格
   - 像素风格

3. **点击"生成脚本"**

**等待时间**：约10-30秒

**生成结果**：
- 场景列表（5-10个场景）
- 角色列表（2-5个角色）
- 场景描述和镜头类型

---

### 步骤4：生成分镜头（1分钟）

**操作流程**：

1. **查看场景列表**
   - 每个场景显示：镜头类型、时长、运镜、画面描述
   - 可以修改场景描述

2. **生成场景图片**
   - 点击"生成全部"按钮
   - 或单独生成某个场景

3. **等待图片生成**

**等待时间**：约30-60秒（5-10张图片）

**生成结果**：
- 16:9比例的场景图片
- 图片自动保存到资产库

---

### 步骤5：添加对白（可选，1分钟）

**操作流程**：

1. **编辑对白**
   - 为每个场景添加角色对白
   - 选择角色和输入台词

2. **生成语音**
   - 点击"生成音频"按钮
   - 选择语音类型（男声/女声）

3. **试听音频**

**等待时间**：约20-40秒

---

### 步骤6：生成角色设计（可选，1分钟）

**操作流程**：

1. **查看角色列表**
   - 主角、配角、龙套

2. **生成角色设计图**
   - 点击"生成角色设计"按钮
   - 自动生成角色外观图

**等待时间**：约30-60秒

---

### 步骤7：一键生成全部（推荐）

**快捷操作**：

完成步骤1后，直接点击"**一键生成全部**"按钮：


**总耗时**：约2-3分钟

**自动完成**：
- ✅ 脚本生成
- ✅ 分镜头图片
- ✅ 对白音频
- ✅ 角色设计图

## 📚 进阶使用

### 场景1：修改生成结果

**修改脚本**：
1. 在步骤1完成后，可以编辑场景描述
2. 重新生成该场景的图片

**调整风格**：
1. 返回步骤1
2. 选择不同风格
3. 重新生成图片

**添加/删除场景**：
1. 在步骤2中手动添加新场景
2. 或删除不需要的场景

---

### 场景2：保存和管理资产

**查看资产库**：
1. 点击侧边栏"资产库"
2. 查看所有生成的故事板
3. 筛选和排序

**下载资产**：
1. 打开资产详情
2. 点击"下载全部"按钮
3. 下载脚本JSON、图片、音频

**分享资产**：
1. 点击"分享"按钮
2. 生成分享链接
3. 发送给他人

---

### 场景3：批量生成

**使用CLI工具**（适合批量生成）：

```bash
# 安装CLI工具
npm install -g @nanoai/cli

# 登录
nanoai login

# 生成故事板
nanoai storyboard generate \
  --input "一只猫在追蝴蝶" \
  --style "卡通风格" \
  --output ./my-storyboard
```

**批量生成脚本**：

```bash
# 从文件读取多个文案
nanoai storyboard batch \
  --input ./scripts.txt \
  --style "卡通风格" \
  --output ./storyboards
```

## 🔧 常见问题

### Q1：生成失败怎么办？

**原因**：
- 网络连接问题
- API服务不可用
- 文案内容违规

**解决方案**：
1. 检查网络连接
2. 查看错误提示信息
3. 修改文案内容后重试
4. 联系技术支持

---

### Q2：生成速度慢？

**正常耗时**：
- 脚本生成：10-30秒
- 图片生成：30-60秒/张
- 音频生成：5-10秒/条
- 总计：2-3分钟

**加速方法**：
1. 使用更简单的文案
2. 减少场景数量
3. 选择更简单的风格
4. 使用本地GPU加速

---

### Q3：如何提高生成质量？

**文案技巧**：
1. ✅ 描述具体，避免抽象
2. ✅ 包含场景、角色、动作
3. ✅ 添加情感和氛围描述
4. ❌ 避免过长或过短

**风格选择**：
- 卡通风格：适合儿童内容
- 写实风格：适合电影感
- 水彩风格：适合艺术感
- 像素风格：适合游戏感

---

### Q4：可以导出哪些格式？

**支持格式**：
- JSON：脚本数据
- PNG：图片文件
- MP3：音频文件
- ZIP：全部文件打包
