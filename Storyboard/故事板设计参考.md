## 1. 系统概述

### 1.1 架构说明

故事板系统采用**前后端分离架构**，支持4步工作流一键生成故事板内容：

```
用户输入文案 → 步骤1脚本生成 → 步骤2分镜头创建 → 步骤3图片生成 → 步骤4角色设计 → 完成
```

**技术栈**：
- **前端**：Next.js 16 + React 19 + Zustand 5 + Tailwind CSS 4
- **后端**：FastAPI + Python 3.11 + Redis + MQTT
- **CLI**：Node.js + TypeScript + Redis Queue

### 1.2 核心功能

| 功能模块 | 描述 | 文件位置 |
|----------|------|----------|
| 故事板向导 | 4步骤向导式生成界面 | [StoryboardWizard.tsx](frontend/components/StoryboardWizard.tsx) |
| 场景展示 | 分镜头卡片网格展示 | [StoryboardPanel.tsx](frontend/components/StoryboardPanel.tsx) |
| 资产卡片 | 故事板资产卡片展示 | [StoryboardAssetCard.tsx](frontend/components/StoryboardAssetCard.tsx) |
| 任务队列 | 任务列表和进度展示 | [StoryboardTaskQueue.tsx](frontend/components/StoryboardTaskQueue.tsx) |
| 任务动画 | 三阶段生成动画 | [StoryboardTaskAnimation.tsx](frontend/components/StoryboardTaskAnimation.tsx) |

## 2. 用户流程

### 步骤1：脚本生成

#### 前端UI组件

**组件**：`Step1Script`（位于StoryboardWizard内部）

**核心功能**：
- 文案输入框
- 风格选择（使用storyboard-categories常量）
- 生成脚本按钮
- 脚本结果展示（场景列表、角色列表）

**状态管理**：`storyboardWizardStore`
```typescript
{
  inputText: string        // 用户输入的文案
  style: string            // 选择的风格
  scriptData: {            // 生成的脚本数据
    scenes: Scene[]        // 场景列表
    characters: Character[] // 角色列表
  }
}
```

#### 后端逻辑

**API端点**：`POST /api/storyboard/generate-script`

**核心流程**：
1. 接收用户文案和风格参数
2. 调用GLM-5模型生成脚本
3. 解析生成结果（场景、角色、对白）
4. 返回结构化脚本数据

**响应格式**：
```json
{
  "scenes": [
    {
      "id": "scene_1",
      "shotType": "远景",
      "duration": "3秒",
      "camera": "固定镜头",
      "description": "画面描述",
      "dialogues": [],
      "narrator": "旁白"
    }
  ],
  "characters": [
    {
      "id": "char_1",
      "name": "角色名",
      "role": "protagonist",
      "appearance": "外貌描述"
    }
  ]
}
```

#### 数据流

```
用户输入文案 → 前端验证 → API调用 → GLM-5生成 → 脚本解析 → 存储到Store → 展示结果
```

### 步骤2：分镜头创建

#### 前端UI组件

**组件**：`Step2Storyboard`（位于StoryboardWizard内部）

**核心功能**：
- 场景列表展示（使用StoryboardPanel组件）
- 场景图片生成按钮
- 批量生成全部场景
- 进度条展示

**状态管理**：`storyboardWizardStore`
```typescript
{
  storyboardImages: string[]  // 场景图片URL数组
}
```

#### 后端逻辑

**API端点**：`POST /api/storyboard/generate-storyboard`

**核心流程**：
1. 接收脚本数据和风格参数
2. 为每个场景生成图片提示词
3. 调用NanoBanana Pro生成图片
4. 返回图片URL数组

**Pipeline流程**（`storyboard_pipeline.py`）：
```python
async def generate_storyboard_images(script: Script, style: str):
    # 为每个场景生成图片
    for scene in script.scenes:
        prompt = build_scene_prompt(scene, style)
        image_url = await nanobanana.generate(prompt)
        storyboard_images.append(image_url)
    return storyboard_images
```

#### 数据流

```
脚本数据 → 提示词构建 → 图片生成API → 图片URL数组 → 存储到Store → 展示场景卡片
```

### 完成

#### 前端UI组件

**操作**：点击"一键生成全部"按钮

**核心功能**：
- 提交所有步骤数据
- 显示生成进度
- 完成后保存到资产库

#### 后端逻辑

**API端点**：`POST /api/storyboard/create-asset`

**核心流程**：
1. 接收完整payload（脚本+图片+对白+角色）
2. 保存到数据库
3. 保存到对象存储（MinIO）
4. 返回资产ID

#### CLI Pipeline（完整工作流）

**文件**：`pipeline/storyboard.ts`

**4步工作流**：
```typescript
// 步骤1：生成脚本（0-30%）
const script = await generateScript(inputText, style)

// 步骤2：生成分镜头（30-50%）
const storyboardImages = await generateStoryboard(script, style)

// 步骤3：生成对白音频（50-80%）
const dialogueAudios = await generateAudio(script.dialogues)

// 步骤4：生成角色设计（80-100%）
const characterDesigns = await generateCharacters(script.characters)
```

**特性**：
- ✅ **断点续传**：从任意步骤恢复执行
- ✅ **自动重试**：失败步骤最多重试3次
- ✅ **错误分析**：调用GLM-5分析失败原因
- ✅ **并行生成**：步骤3和4可并行执行
- ✅ **进度回调**：实时推送进度到MQTT/Redis

## 4. 数据结构

### 4.1 前端类型定义

**StoryboardAsset**（故事板资产）：
```typescript
interface StoryboardAsset {
  id: string
  title: string
  synopsis?: string
  script: {
    scenes: StoryboardScene[]
    characters: Character[]
  }
  storyboardImages: string[]
  dialogueAudios: DialogueAudio[]
  characterDesigns: CharacterDesign[]
  createdAt: string
}
```

**StoryboardScene**（场景）：
```typescript
interface StoryboardScene {
  id: string
  shotType: string      // 镜头类型：远景、中景、近景
  duration: string      // 时长：3秒
  camera: string        // 运镜：固定镜头、推镜头
  description: string   // 画面描述
  dialogues: Dialogue[] // 对白列表
  narrator?: string     // 旁白
}
```

**Dialogue**（对白）：
```typescript
interface Dialogue {
  dialogueId: string
  sceneId: string
  characterId: string
  characterName: string
  text: string
}
```

**StoryboardTask**（任务）：
```typescript
interface StoryboardTask {
  id: string
  title: string
  status: StoryboardTaskStatus
  progress: number
  error?: string
  createdAt: string
}

type StoryboardTaskStatus =
  | 'pending'
  | 'generating_script'
  | 'generating_storyboard'
  | 'generating_characters'
  | 'generating_audio'
  | 'success'
  | 'error'
```

**StoryboardSubTask**（子任务）：
```typescript
interface StoryboardSubTask {
  id: string
  label: string
  status: 'pending' | 'running' | 'success' | 'error'
  progress: number
}
```

### 4.2 后端Schema定义

**StoryboardCreate**（创建故事板）：
```python
class StoryboardCreate(BaseModel):
    input_text: str
    style: str
```

**StoryboardResponse**（故事板响应）：
```python
class StoryboardResponse(BaseModel):
    id: str
    title: str
    synopsis: Optional[str]
    script: Script
    storyboard_images: List[str]
    dialogue_audios: List[DialogueAudio]
    character_designs: List[CharacterDesign]
    created_at: datetime
```

### 4.3 数据流转

```
用户输入文案 → 脚本生成 → 场景列表 → 图片生成 → 图片URL数组 → 音频生成 → 音频URL → 角色设计 → 角色设计图 → 保存资产
```

## 5. 性能优化

### 5.1 前端优化策略

**React性能优化**：
- `useMemo`：缓存计算结果（场景图片映射、对白摘要）
- `useCallback`：缓存事件处理函数
- `React.memo`：组件记忆化（StoryboardPanel、StoryboardAssetCard）

**代码分割**：
- 动态导入：`lazy(() => import('./StoryboardWizard'))`
- 路由级分割：每个页面独立打包

**图片优化**：
- 懒加载：`onLoad`事件控制图片淡入
- 模糊占位符：加载时显示loading动画
- 响应式图片：`aspect-video`保持16:9比例

**状态管理优化**：
- Zustand持久化：`persist`中间件
- 选择器优化：避免不必要的重渲染

### 5.2 后端优化策略

**缓存策略**：
- Redis缓存脚本生成结果（TTL: 1小时）
- 图片CDN缓存（TTL: 24小时）

**并行处理**：
- 异步任务队列：Redis + RQ
- 并行图片生成：`asyncio.gather`

**数据库优化**：
- 索引优化：`user_id`、`created_at`
- 分页查询：`limit`、`offset`

### 5.3 缓存机制

**多层缓存**：
```typescript
// L1：内存缓存（5分钟）
await cacheManager.get('api:user', { userId }, fetchData, { memoryTTL: 5 * 60 * 1000 })

// L2：IndexedDB缓存（1小时）
```

## 6. 错误处理

### 6.1 前端错误处理

**错误边界**：
```tsx
<ErrorBoundary fallback={<ErrorScreen />}>
  <StoryboardWizard />
</ErrorBoundary>
```

**Toast提示**：
```typescript
toast.success('故事板已保存')
toast.error('生成失败，请重试')
```

**重试机制**：
```typescript
const retry = async (fn, maxRetries = 3) => {
  for (let i = 0; i < maxRetries; i++) {
    try {
      return await fn()
    } catch (error) {
      if (i === maxRetries - 1) throw error
    }
  }
}
```

### 6.2 后端错误处理

**异常捕获**：
```python
try:
    result = await generate_script(input_text)
except Exception as e:
    logger.error(f"Script generation failed: {e}")
    raise HTTPException(status_code=500, detail=str(e))
```

**重试装饰器**：
```python
@retry(max_attempts=3, backoff_rate=2)
async def generate_image(prompt):
    return await nanobanana.generate(prompt)
```
