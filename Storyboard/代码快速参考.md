### 3. services/storyboard_pipeline.py（~720行）

**功能**：Pipeline工作流实现

**核心流程**：
```python
async def execute_storyboard_pipeline(
    input_text: str,
    style: str,
    progress_callback: Callable[[int, str], None]
) -> StoryboardAsset:
    """执行完整的4步工作流"""
    
    # 步骤1：生成脚本（0-30%）
    script = await generate_script(input_text, style)
    progress_callback(30, "脚本生成完成")
    
    # 步骤2：生成分镜头（30-50%）
    storyboard_images = await generate_storyboard_images(script, style)
    progress_callback(50, "分镜头生成完成")
    
    # 步骤3：生成音频（50-80%）
    dialogue_audios = await generate_audio(script.dialogues)
    progress_callback(80, "音频生成完成")
    
    # 步骤4：生成角色设计（80-100%）
    character_designs = await generate_characters(script.characters)
    progress_callback(100, "角色设计生成完成")
    
    return StoryboardAsset(...)
```

**特性**：
- 断点续传：从任意步骤恢复
- 自动重试：失败步骤最多重试3次
- 错误分析：调用GLM-5分析失败原因
- 进度回调：实时推送进度

### 5. workers/storyboard_worker.py（~200行）

**功能**：故事板后台任务处理

**核心任务**：
```python
@worker.task
def process_storyboard_task(task_id: str, payload: dict):
    """处理故事板生成任务（后台异步）"""
    
    try:
        # 执行Pipeline
        asset = await execute_storyboard_pipeline(
            payload['input_text'],
            payload['style'],
            lambda progress, msg: update_task_progress(task_id, progress, msg)
        )
        
        # 保存资产
        asset_id = await save_asset(asset)
        
        # 更新任务状态
        update_task_status(task_id, 'success', asset_id=asset_id)
        
    except Exception as e:
        # 错误处理
        update_task_status(task_id, 'error', error=str(e))
```

## 📁 CLI Pipeline代码说明

### pipeline/storyboard.ts（~260行）

**功能**：4步工作流Pipeline实现（CLI版本）

**核心流程**：
```typescript
export async function executeStoryboardPipeline(
  inputText: string,
  style: string,
  options: PipelineOptions
): Promise<StoryboardAsset> {
  
  const { mqttClient, redis, progressCallback } = options
  
  // 步骤1：生成脚本（0-30%）
  const script = await generateScript(inputText, style)
  await progressCallback(30, '脚本生成完成')
  
  // 步骤2：生成分镜头（30-50%）
  const storyboardImages = await generateStoryboardImages(script, style)
  await progressCallback(50, '分镜头生成完成')
  
  // 步骤3：生成音频（50-80%）
  const dialogueAudios = await generateAudio(script.dialogues)
  await progressCallback(80, '音频生成完成')
  
  // 步骤4：生成角色设计（80-100%）
  const characterDesigns = await generateCharacters(script.characters)
  await progressCallback(100, '角色设计生成完成')
  
  return {
    id: generateId(),
    title: inputText.substring(0, 50),
    script,
    storyboardImages,
    dialogueAudios,
    characterDesigns,
    createdAt: new Date().toISOString()
  }
}
```

**特性**：
- MQTT进度推送
- Redis状态同步
- 断点续传（保存中间状态）
- 错误重试（最多3次）
- 子任务并行（步骤3和4）

**使用场景**：CLI命令、后台任务

import { StoryboardWizard } from '@/components/storyboard/StoryboardWizard'

function MyPage() {
  const [open, setOpen] = useState(false)

  return (

}
